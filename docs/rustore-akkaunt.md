# Аккаунт разработчика RuStore

Зачем: публикация приложения «Порог» в RuStore (Android) и подключение подписок через RuStore Pay SDK.

Связанные задачи из `plan-checklist.md`: раздел 6 «RuStore — бесплатная версия», раздел 8 «Платные тарифы».

## Факты (проверено 19.11.2026)

- Регистрация в консоли бесплатна, нужен только VK ID.
- Физлицо может публиковать приложения, но **не может** подключать монетизацию (с 01.02.2026 — только ИП/юрлица).
- Для аккаунта ИП нужна УКЭП или подтверждённый профиль VK Бизнес ID.
- Комиссия RuStore с платежей — от 15 %.
- Модерация приложения — ориентировочно до 3 дней; обновления часто за час.

## Стратегия: два варианта

### Вариант А (рекомендуется): сразу аккаунт ИП
1. Дождаться регистрации ИП (ветка `ip-registration`).
2. Подтвердить VK Бизнес ID.
3. Зарегистрировать аккаунт в консоли RuStore с типом «ИП»: https://www.rustore.ru/developer
4. Завести отдельный рабочий VK ID под компанию, чтобы аккаунт не был привязан к личному.

### Вариант Б: сначала физлицо, потом перенос
Если бесплатную версию нужно опубликовать раньше, чем будет ИП:
1. Зарегистрировать аккаунт физлица по VK ID, опубликовать бесплатную версию (раздел 6 плана).
2. После регистрации ИП создать второй аккаунт как ИП (монетизацию пока не подключать).
3. Написать в support@rustore.ru с темой «Сохранить текущий VK ID и обновить правовую форму».
4. После ответа поддержки подключить монетизацию и запросить перенос приложений в новый аккаунт.
5. Обновить API-ключи RuStore в приложении после переноса.
