# Регистрация ИП для «Порога»

Зачем: с 1 февраля 2026 монетизация в RuStore (подписки, RuStore Pay SDK, платные приложения) доступна только ИП и юрлицам. Без ИП не подключить подписку.

Связанные задачи из `plan-checklist.md`: раздел 8 «Платные тарифы».

## Решение: ИП на НПД (самозанятый ИП)

- Налог 4 % (с физлиц) / 6 % (с юрлиц), лимит дохода 2,4 млн ₽/год.
- Нет фиксированных страховых взносов (в отличие от УСН).
- Нельзя нанимать сотрудников по трудовым договорам.
- Если уже есть самозанятость — статус ИП добавляется к ней, НПД сохраняется.

## Шаги

1. Выбрать банк, который бесплатно регистрирует ИП онлайн (Сбер, Т-Банк, Альфа и др.) — заодно откроют расчётный счёт. Альтернатива: самостоятельно через сайт ФНС или Госуслуги.
2. Подать заявление (форма Р21001): ОКВЭД — 62.01 (разработка ПО), можно добавить 63.11.1 (обработка данных, хостинг), 68.20 (аренда собственного имущества — пригодится, если есть своя сдаваемая недвижимость).
3. Дождаться регистрации (обычно до 3 рабочих дней), получить выписку из ЕГРИП.
4. Проверить, что в «Мой налог» статус НПД сохранился / активировать его.
5. Подтвердить профиль **VK Бизнес ID** как ИП (бесплатно, онлайн) — понадобится для аккаунта RuStore. Альтернатива — УКЭП от ФНС (бесплатно, но нужен сертифицированный токен, ~2–4 тыс ₽).

## Чек-лист

- [ ] Выбрать банк и подать заявление Р21001
- [ ] Получить выписку ЕГРИП
- [ ] Проверить статус НПД в «Мой налог»
- [ ] Подтвердить VK Бизнес ID (или получить УКЭП)
- [ ] Открыть расчётный счёт (обычно автоматом с банком)
- [ ] Отметить галочки в разделе 8 `plan-checklist.md`

## Заметки

- Аккаунт RuStore оформлять на ИП, а не на физлицо, если подписка планируется с первого релиза.
- Чеки НПД по оплатам подписки выставляет сам RuStore как агент? — уточнить у поддержки/бухгалтера перед включением платных тарифов.
