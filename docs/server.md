# Сервер для «Порога»

Зачем: синхронизация между устройствами, связка хозяин ↔ арендатор (приглашения, оплаты, показания, заявки), вход по СМС, хранение фото, страница-приглашение на своём домене, веб-экран арендатора для iPhone.

Связанные задачи из `plan-checklist.md`: раздел 7 «Сервер». Первая Flutter-версия (раздел 4) работает без сервера — поднимать его раньше времени не нужно.

## Требования

- **152-ФЗ**: персональные данные (телефоны, паспорта, адреса) — только на серверах в РФ.
- Минимум на старте: 1–2 ГБ RAM, 20–40 ГБ диск — хватит на API, PostgreSQL и хранилище фото.
- HTTPS с бесплатным сертификатом (Let's Encrypt).
- Резервные копии БД и файлов с первого дня.

## Что хостить

1. Бэкенд API + PostgreSQL. Варианты: PocketBase (один бинарник, БД + авторизация + файлы из коробки) или self-hosted Supabase, либо свой бэкенд.
2. Статика: страница-приглашение `i.html` на своём домене и веб-экран арендатора (Flutter Web).
3. Push — RuStore Push SDK (бесплатно).
4. СМС-коды — внешний провайдер (smsaero, smsc.ru и др.), ~1,5–3 ₽/сообщение; для договора, скорее всего, понадобится ИП (ветка `ip-registration`).

## Варианты хостинга (цены ориентировочные, проверено 19.11.2026)

| Провайдер | Минимальный VPS | Примечание |
|---|---|---|
| RuVDS | ~130–200 ₽/мес | Дёшево, простая панель, ДЦ в РФ |
| Selectel | ~200 ₽/мес (1 vCPU / 1 ГБ / 10 ГБ, с IP) | Сильная инфраструктура, 152-ФЗ, S3 |
| Timeweb Cloud | ~300 ₽/мес | Готовые образы, удобная панель |

Плюс домен .ru — ~200 ₽ за первый год (продление ~400 ₽/год).
